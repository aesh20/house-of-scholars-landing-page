# House of Scholars – Responsive Landing Page

## Project Description
House of Scholars is an educational landing page designed to introduce students to learning opportunities, courses, and scholarships.

## Target Audience
Students and young learners seeking educational resources, skill development, and scholarship opportunities.

## Features
- Header with logo and navigation links.
- Hero section highlighting the educational platform.
- Three feature cards for courses, scholarships, and continued learning.
- Responsive design concept for desktop and mobile.
- Reusable components and Auto Layout in Figma.

## Design Choices
The design uses purple, lavender, and pink to create a modern educational identity. Clear typography, consistent spacing, and organized sections improve readability and navigation.

## Tools Used
- Figma
- Auto Layout
- Reusable Components
- Color and Typography Styles
